# Чек-лист Python quality

## Контракт

- Имя отражает предметный смысл.
- Типы входа/выхода и исключения ясны.
- Boundary validation выполняется один раз в понятном месте.
- Breaking change отмечен и протестирован.

## Простота

- Один уровень абстракции внутри функции.
- Нет глубокой вложенности и скрытых mutations.
- Abstraction имеет минимум два реальных применения либо необходима как protocol boundary.
- Нет почти одинаковых моделей и helpers.

## Надёжность

- Ошибка не теряет первопричину.
- Cancellation/timeout не проглатываются.
- Resource lifecycle закрывается через context managers.
- Async код не выполняет blocking I/O.

## Читаемость

- Идентификаторы английские и предметные.
- Русский комментарий объясняет «почему».
- Нет комментариев к очевидным присваиваниям и циклам.
- Публичный docstring описывает контракт, а не реализацию.
