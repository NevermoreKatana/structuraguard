# Системная отладка

## Вход

Команда воспроизведения, входные данные, ожидаемое и фактическое поведение, доступный trace.

## Результат

Доказанная первопричина, regression test, минимальное исправление и результаты проверок.

## Workflow

1. Зафиксируй точную команду, вход, ожидаемое и фактическое поведение.
2. Воспроизведи дефект до изменения кода. Сохрани минимальный error trace и границу слоя, где нарушается инвариант.
3. Сузь область: source → parser → normalized model → mapper → validator → staging → loader.
4. Сформулируй не более трёх проверяемых гипотез и проверяй по одной.
5. Найди первопричину, а не место последнего исключения. Проследи данные назад до первого неверного состояния.
6. Добавь regression test, который падает на старом поведении.
7. Исправь первопричину минимально; не маскируй симптом retry, default value или broad exception.
8. Запусти regression test, соседние tests и quality gates.
9. Кратко сообщи: причина, доказательство, исправление, проверка.

Используй [диагностический чек-лист](references/DEBUG_CHECKLIST.md) для сложного дефекта.
