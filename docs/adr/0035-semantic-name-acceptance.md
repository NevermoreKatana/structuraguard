# ADR 0035 — Семантическое соответствие разных названий полей

Статус: принято. Дата: 2026-09-23. Уточняет confidence policy ADR 0020.

## Причина

Смесь 80% M9 lexical/base score и 20% LLM не позволяла принять даже однозначное
семантическое соответствие с оценкой 0.99, если имена различались. При сборке
`MappingPlan` дополнительно терялась принятая M10 оценка: сохранялся старый M9
confidence. Пользователь явно требует, чтобы SDK самостоятельно принимал разные
названия и опечатки при уверенном, проверенном выборе модели.

## Решение

`SemanticMappingOptions.llm_weight` имеет диапазон 0–1 и default 1. Проверенный
семантический сигнал заменяет предварительную lexical гипотезу. Явное значение
0.20 сохраняет прежнюю смесь; существующие пороги auto/review и штрафы действуют.
Настройки M10 доступны через `SDKDependencies.semantic_mapping`.

Это не разрешение доверять произвольному self-confidence. Модель обязана оценить
всех переданных кандидатов из scope, вернуть закрытые IDs, согласованное покрытие
полей/таблиц/FK и достаточный разрыв с конкурентами. SDK независимо проверяет
membership, типы, coverage, collisions, security и допустимость FK. Скрытые top-k
конкуренты при максимальном весе всегда сохраняют review. Hard blockers нельзя
снять высоким числом или нулевым штрафом. M11 и проверки записей обязательны.

При сборке плана используются принятые scores полей; confidence плана учитывает
также выбранные таблицы и связи. Низкий score приводит к confirm/reject, а не к
молчаливому переименованию. Backend не дублирует выбор полей. Различия регистра,
разделителей и единичные опечатки остаются объяснимым M9 evidence; LLM разрешает
семантические варианты только в пределах проверенного каталога.

## Последствия

Меняется default confidence policy, но явно заданный старый вес совместим.
Wire-формат ответа модели, MappingPlan и FieldMapping не меняется; dependency
и полномочия модели не расширены. Оценка остаётся эвристической, не статистической
вероятностью: корректность реальных значений определяют последующие проверки SDK.
