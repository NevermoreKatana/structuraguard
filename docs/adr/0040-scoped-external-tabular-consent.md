# ADR 0040 — Ограниченное согласие на внешнее табличное планирование

Статус: принято. Дата: 2026-09-29.

Планировщик ADR 0036 безусловно требовал LOCAL_ONLY. Из-за этого выбранная
внешняя модель могла разобрать документ, но этап сопоставления останавливался
до обращения к ней. Пользователь явно разрешил передачу выборки конкретного
источника, схемы конкретной таблицы и только сохранённому получателю.

LOCAL_ONLY остаётся поведением без отдельного согласия. FIXED допускается с
`TabularExternalApproval`: fingerprints полного табличного snapshot, каталога,
scope и routing policy; пределы числа строк и длины значений. SDK проверяет все
привязки и лимиты до сканирования и generation. Fallback не добавляется.

Trusted host отвечает за подлинность согласия: DTO не является UI-согласием и
не должен формироваться из недоверенного payload. Песочница проверяет отдельную
зашифрованную серверную запись оператора, привязанную к проекту, исходному файлу,
точному подготовленному snapshot, таблице/схеме и deployment получателя. Запись
не создаётся настройками проекта или запросом pipeline. Изменение любого
элемента запрещает передачу; удаление подключения отзывает согласие.

Согласие не отменяет classification, запрет secrets, RESTRICTED cloud,
injection scanner, exact security approval, router budgets или проверку плана
по всем строкам. Значения и endpoint не включаются в ошибки согласия.

Проверки: явное согласие с FIXED/cloud, каждый несовпавший fingerprint, превышение
выборки, прежний отказ без согласия, запреты secrets/RESTRICTED/injection/fallback.
