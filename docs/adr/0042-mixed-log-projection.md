# ADR-0042: План смешанных syslog-событий

Статус: принято.

## Причина

Одна entity с JSON-селекторами для всего файла применяла пути к HTTP-тексту.
Общая grammar также позволяла модели выдумывать JSON-пути для полей envelope.
Исполнитель правильно отклонял такой план, но модель не получала достаточных
ограничений при генерации.

## Решение

Группировать scalar JSON paths из подтверждённых replay samples, а отдельные
ISO syslog-события без поддерживаемой scalar shape сохранять целиком.
Только при полном disjoint покрытии каталога и соблюдении лимитов fields/entities
native schema связывает каждую группу со своими field IDs, selector, refs и
однострочными records. Семантические имена, типы JSON-полей и смысл entities
определяет LLM. Schema version — `1.4.0`, prompt — `1.1.4`.

Исполнитель сохраняет порядок физических строк. Полная проверенная partition
тех же однострочных записей считается уточнением raw-record плана при оценке
agreement, без искусственного штрафа. Перестановка записей внутри группы,
изменение границ, identity или иерархии не входят в это исключение.

## Ограничения и безопасность

Непопавшие в samples строки не классифицируются догадкой. Продолжения multiline
событий без envelope не объявляются отдельными records. Неполная partition или
превышение limits сохраняют общий путь построения плана. Не добавляются сети,
вычисляемые выражения, изменение source или автоматическое исправление ответа.
Отсутствующие JSON-ключи остаются ошибкой; явный JSON null сохраняется.
Все source refs, типы, coverage и значения повторно проверяются на исходнике.

## Проверки

Native HTTP mock и реальный semantic replay: JSON разных shapes вперемежку с
HTTP-текстом, исходный порядок, provenance, batch boundaries и оценка confidence.
Отрицательные случаи: выдуманный путь, JSON на текстовой строке, потеря/дублирование/
перестановка событий, непроверенный sample, продолжение stack trace и лимиты.
